1. OPEN IN BROWSER
   → Open any HTML file (e.g., INDEX.HTML)
   → Navbar and footer will auto-load
   → All styling will apply automatically

2. MAKE CHANGES
   → Edit navbar/footer: assets/html/navbar-footer.html
   → Edit colors: assets/css/theme.css (update :root variables)
   → Edit page content: Directly in HTML files

3. ADD NEW PAGES
   → Create new HTML file
   → Include: <link rel="stylesheet" href="assets/css/theme.css">
   → Include: <script src="assets/js/components.js"></script>
   → Navbar/footer auto-load!

4. UPDATE THEME
   → Change one color in theme.css
   → ALL pages update automatically!
